---
term: Agent
definition: "A system that runs a model in a loop: given a goal, it decides the next step, calls tools, observes the result and continues until it stops or hands back. An agent differs from a chat (no loop) and from a workflow (a fixed sequence) because the model chooses the steps. That flexibility is useful for open-ended work — and it is why agents need limits, budgets and approval points."
