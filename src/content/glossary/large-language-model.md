term: Large language model (LLM)
definition: "A large language model is an AI system trained on enormous amounts of text to predict the next token in a sequence. When you send a message, it generates the reply one token at a time — which is why it can sound fully fluent while still getting facts wrong."

Large language models are the engine behind most text-based AI products. "Large" refers to the number of parameters the model learned during training — not to the size of the text you give it; that is covered by the context window.
