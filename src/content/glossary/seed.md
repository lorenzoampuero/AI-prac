definition: "A number that fixes the starting point of a generation's randomness. Where a tool exposes one, the same seed plus the same settings produces a similar — not identical — result, which helps keep a series stable. Change anything else (wording, settings, model version) and the seed's effect changes with it. A repeatability dial, not a guarantee."
