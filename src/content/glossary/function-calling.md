---
term: Function calling
definition: "A mechanism where the model, instead of inventing an answer, asks the surrounding system to run a named tool — check a calendar, look up an order, send a message — and continues with the tool's result. The model proposes the call; your system decides whether to execute it. Permissions, confirmation steps and audit trails belong on that side of the line."
